Creating Cost Expressions

Read each scenario and write an algebraic expression for the total cost. Use only integers (whole numbers).

1. A taxi charges a flat fee of $4 plus $2 per mile driven. Write an expression for the total cost of a ride of m miles.
2. A tool rental store charges a $20 reservation fee and $15 per hour. Write an expression for renting the tool for h hours.
3. A car rental costs $50 for the day, which includes the first 50 miles. Each additional mile costs $2. Write an expression for driving m miles (where m > 50).
4. A catering service charges a fixed hall setup fee of $200, plus $25 per adult meal (a) and $15 per child meal (c). Write an expression for the total cost.
